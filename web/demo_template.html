Show it once.

EIDOS watches a screen-recorded tutorial and turns it into a program an AI agent can run. Every step carries a visual contract taken from the video, so the agent checks its own work, and the skill keeps working when the data, the design, or the whole app changes.

  • Learns from an ordinary video. No recorder, no scripts, no app access.
  • Learns what each step is for, not where the pixels were.
  • Checks every step against what the person was seen doing.

    Where Meta's models come in

    EIDOS is built around four Meta models. This demo runs the same pipeline offline, with classic computer vision standing in for each model, so every result on this page is reproducible without an API key. With a key, each stand-in is swapped for the model on its row.

    Model
    Job in EIDOS
    Offline stand-in used on this page
    SAM 3.1
    Tracks the pointer and click markers through the video, segments the region each step changed, and finds a control on a new screen from a text concept like "bold text button".
    Color segmentation, frame differencing, and template matching.
    Muse Spark
    Reads each before and after pair and says what the step was for, in terms that do not depend on pixels.
    OCR plus table rules that map positions to column names and row roles.
    Muse Wonder
    Generalizes the step trace into a program: inputs, relative targets, formulas explained in terms of the table, and the contract for each step.
    Rules for the step types this pilot covers.
    Muse Image
    Draws a card for each learned skill so a library of skills can be browsed at a glance.
    Not used offline.
