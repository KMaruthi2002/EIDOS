Show it once.

EIDOS watches a screen-recorded tutorial and compiles it into a skill: a small program an AI agent can run on screens the video never showed. Every step carries a visual contract taken from the video, so the agent checks its own work, repairs what went wrong, and says so when it can't.

    Four everyday tasks, one video each

    Each tutorial below was recorded once in design A of a small app. From the pixels alone, EIDOS finds every click, reads the labels, and writes a program: targets named by their label, typed values turned into inputs, and a contract for every step. One engine, four kinds of step: press, type, choose, switch.

            Running on Meta's models

            Designs A and B, and the spreadsheets, need no model: those results run offline with classic computer vision, so anyone can reproduce them without a key. Meta's models come in where pixels and OCR aren't enough, and every answer a model gives is checked against the screen.

            Muse Spark
            When a learned label isn't on the new screen, picks the text that plays the same role (To becomes Recipient, Send becomes Deliver), and maps a press's expected phrases to the new wording.
            It must pick from text read off this screen; EIDOS then finds that text from pixels and checks the step's contract as usual.
            SAM 3.1
            A second opinion on where each field, button and switch is ("input box", "Deliver button", "toggle switch").
            Advisory: compared with the box found from pixels, never overrides it. On the design C runs it agreed on 109 of 151 checks.
